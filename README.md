# PrevenLab Arcade · SEGU

Juegos HTML gratuitos de prevención y seguridad (PrevenLab Academy). Cada juego es un único `index.html` en su carpeta.

- `segu-tension/` · **SEGU Adultos**: Segu y la Tensión (EPP para riesgo eléctrico).
- `segu-kids/` · **SEGU Kids**: Detective de Peligros. Se genera desde el original de OneDrive con `python tools/build_kids.py` (no editar a mano).
- `assets/segu.svg` · el personaje. `fonts/` · Nunito alojada (licencia OFL). `tools/make_og.py` · imágenes para compartir.

Criterio para el grupo Kids: sin registro, sin datos, sin enlaces ni compartir, sin pedidos a servidores externos.
